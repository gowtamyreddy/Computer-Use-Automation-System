# Evidence

Generated by `python scripts/run_demo.py` (needs `OPENAI_API_KEY`); see `SUMMARY.md` once generated.

- `discovery/<capability>/`: genuine LLM discovery runs: `events.jsonl` (every decision with its rationale),
  `llm_transcript.jsonl` (redacted prompts and tool calls), `system_prompt.json`, masked `screens/`, `artifact.yaml`
- `artifact_*.yaml`: the saved capability artifacts
- `replays/<scenario>/`: deterministic replays: `events.jsonl`, `result.json` (outputs stored as fingerprints),
  masked `screens/`, redacted `dom/` snapshots on failure, `interventions/` for the human handoff
